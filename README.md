## Rolagem, PV/PP e OBS (unificado)

A rolagem de dados, o Índice de Dano, a Pressão e os overlays do OBS agora fazem parte desta aplicação (tudo no Supabase).

**Para ativar:** execute `supabase/migration-live-rolls-labels.sql` no SQL Editor do Supabase (é aditivo; não altera `sheets`).

**Links do OBS** (Fonte de Navegador, 1920×1080, fundo transparente) — copie pelo Painel do Mestre, botões *OBS ROLAGEM* e *OBS INTEGRIDADE*:
- `/obs/<id-da-ficha>/rolagem`
- `/obs/<id-da-ficha>/integridade`

**Nomenclatura:** Painel do Mestre → *Editar nomes da ficha*. Só o texto exibido muda; as chaves dos dados permanecem.
